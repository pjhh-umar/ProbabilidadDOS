Ejercicios propuestos primer examen parcial

Ejercicio

Sean $X$ y $Y$ variables aleatorias con función de distribución conjunta $F(x,y)$. Demuestre que para cualesquiera números reales $a < b$ y $c < d$, $$\mathbb{P}(a < X \leq b, c < Y \leq d) = F(b,d) + F(a,c) - F(a,d) - F(b,c).$$

Ejercicio

Sean $X_1, X_2$ y $X_3$ variables aleatorias con función de distribución conjunta $F(x_1, x_2, x_3)$. Demuestre que para cualesquiera números reales $a_1 < b_1$, $a_2 < b_2$ y $a_3 < b_3$, \[ \begin{align*} \mathbb{P}(a_1 < X_1 \leq b_1, a_2 < X_2 \leq b_2, a_3 < X_3 \leq b_3) &= F(b_1, b_2, b_3) - F(a_1, b_2, b_3) - F(b_1, a_2, b_3) - F(b_1, b_2, a_3) \\ &\quad + F(a_1, a_2, b_3) + F(a_1, b_2, a_3) + F(b_1, a_2, a_3) \\ &\quad - F(a_1, a_2, a_3). \end{align*} \]

Ejercicio

Demuestra que las siguientes funciones son funciones de distribución.

  1. $\displaystyle{ F(x,y) = \begin{cases} (1 - e^{-x})\displaystyle{\left(\frac{1}{2} + \frac{1}{\pi} \tan^{-1} y\right)}, & \text{para } x > 0, \ y \in \mathbb{R}.\\ 0 & \text{d.o.f} \end{cases}} $

  2. $\displaystyle{ F(x,y) = \begin{cases} 1 - e^{-x} - e^{-y} + e^{-x-y}, & \text{para } x, y > 0. \\ 0 & \text{d.o.f} \end{cases}} $

Ejercicio

Determina si las siguientes funciones son funciones de distribución.

  1. $\displaystyle{F(x,y) = \begin{cases} 1 - e^{-xy}, & \text{para } x, y > 0\\ 0, & \text{d.o.f}.\end{cases} }$

  2. $\displaystyle{ F(x,y) = \begin{cases} 1 - e^{-x-y}, & \text{para } x, y > 0.\\ 0 & \text{d.o.f} \end{cases}}$

Ejercicio

Demuestre que la siguiente función no es una función de distribución. Extienda este resultado al caso \displaystyle{ n }-dimensional.

  1. $\displaystyle{ F(x,y,z) = \begin{cases} 0, & \text{si } x + y + z < 0, \\ 1, & \text{si } x + y + z \geq 0. \end{cases} }$

Ejercicio

Demuestre que la siguiente función no es de distribución.

  1. $\displaystyle{ F(x,y) = \begin{cases} \min\{1, \max\{x, y\}\}, & \text{si } x, y > 0, \\ 0, & \text{otro caso}. \end{cases} }$

Ejercicio

Sean $F(x)$ y $G(x)$ dos funciones de distribución. Demuestre o proporcione un contraejemplo para las siguientes afirmaciones.

  1. $ F(x)G(x) $ es una función de distribución univariada.

  2. $ F(x)G(y) $ es una función de distribución bivariada.

  3. $ F^n(x) $ es una función de distribución univariada.

  4. $ F^n(x)G^m(y) $ es una función de distribución bivariada.

Ejercicio

  1. Sea \( X \sim \text{Bernoulli} \left( \displaystyle{\frac{1}{3}} \right) \) y \( Y = 4X - 2 \). Calcule la función de distribución conjunta \( F_{X,Y} \).

  2. Sea \( X \sim \text{Bernoulli} \left( \displaystyle{\frac{1}{4}} \right) \) y \( Y = -7X \). Calcule la función de distribución conjunta \( F_{X,Y} \).
